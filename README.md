# 🎮 Tic-Tac-Toe Game
This is a simple and interactive Tic-Tac-Toe game developed using HTML, CSS, and JavaScript.
The main highlight of this project is that the background color changes every time the player switches, making the gameplay more dynamic and visually engaging. [Play here](https://guibis.github.io/tic-tac-toe/)

---

## 🧩 Features
- Two-player Tic-Tac-Toe game
- Turn-based system between X and O
- 🎨 **Background color changes** on every player turn
- Win detection
- Draw (tie) detection
- Simple and intuitive interface

---

## 🚀 Technologies Used
- **HTML5** – Game structure
- **CSS3** – Styling and dynamic background colors
- **JavaScript** – Game logic and turn control
